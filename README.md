# PromptForge AI — Free-Only Auto Router (Vercel)

واجهة عربية RTL لوكيل هندسة البرومبتات، مع وضع تلقائي يحاول استخدام نماذج مجانية فقط وينتقل إلى بديل إذا فشل النموذج.

## ما الذي يفعله الوضع التلقائي؟

- يكتشف النماذج عبر كتالوج Pollinations API وكتالوج OpenRouter عند الطلب، مع تخزين مؤقت للكتالوج لمدة 60 ثانية.
- يرشّح نماذج Pollinations التي يوضح الكتالوج أن أسعارها صفر، ويستخدم `openrouter/free` ونماذج OpenRouter التي يعلن كتالوجها أنها مجانية (`:free` وتسعير صفر).
- يختبر اتصالاً حقيقياً بالمزودين، ويعرض حالة كل واحد.
- إذا فشل النموذج أو تعذر الوصول إليه أو تجاوز حد الاستخدام، ينتقل إلى النماذج المجانية التالية. لا ينتقل إلى نموذج مدفوع في الوضع التلقائي.
- يعرض اسم المزوّد والنموذج اللذين نجحا وعدد المحاولات الفاشلة السابقة.
- لا يتطلب مفاتيح API في GitHub أو Vercel Environment Variables؛ المستخدم يدخل مفاتيحه من داخل الموقع. تُرسل المفاتيح إلى دالة الخادم فقط عند الطلب.

## مهم بخصوص المجانية

- المجانية ليست ضماناً لاستمرار الخدمة؛ قد تتغير الأسعار أو حصص الاستخدام أو سياسات المزوّد.
- OpenRouter يفرض حدود استخدام على النماذج المجانية، وPollinations قد يعرض نماذج مجانية ومدفوعة في الكتالوج. لذلك لا نستخدم في الوضع التلقائي إلا النماذج التي تظهر بيانات الكتالوج أنها مجانية.
- إذا لم يكشف كتالوج Pollinations بيانات سعر واضحة، يتعامل النظام مع النموذج على أنه غير مؤكّد ويستبعده احتياطياً.
- Groq وCohere متاحان في الوضع اليدوي فقط؛ لأن كون الاستخدام مجانياً يعتمد على خطة/حصة الحساب، ولا يمكن إثبات أن الطلب لن ينتج عنه أي تكلفة من معرف النموذج وحده. لا تستخدم الوضع اليدوي إذا كان شرطك عدم دفع أي مبلغ.
- مفاتيح API هي مفاتيح المستخدم نفسه. لا يوجد تجاوز لحدود الخدمة أو للحصص المجانية.

## النشر على Vercel من التابلت

1. فك ضغط المشروع.
2. أنشئ مستودعاً جديداً على GitHub وارفع **محتويات** المجلد مع الحفاظ على `public/` و`api/` وملف `vercel.json` في الجذر.
3. في Vercel اختر Add New → Project ثم استورد المستودع واضغط Deploy.
4. افتح الموقع المنشور، واختر «تلقائي — النماذج المجانية فقط».
5. أدخل مفتاح Pollinations و/أو OpenRouter.
6. اضغط «تحديث النماذج المجانية» ثم «اختبار المزودين».
7. اكتب فكرة واضغط «شغّل الوكيل الذكي».

## هيكل الملفات

- `public/index.html` — الواجهة وإعدادات المفاتيح.
- `api/agent.js` — اكتشاف النماذج، اختبار الاتصال، التوجيه الاحتياطي، واستدعاء النماذج.
- `vercel.json` — توجيه واجهة الموقع ودالة API.

## ملاحظات أمنية

- لا ترفع مفاتيح API إلى GitHub أو تضعها في ملفات المصدر.
- خيار حفظ المفاتيح اختياري ويستخدم `localStorage` في المتصفح؛ لا تفعّله على جهاز مشترك.
- الموقع يستخدم API keys التي يدخلها الزائر؛ أضف تسجيل دخول وحدود استخدام قبل فتحه للعامة لتجنب إساءة الاستخدام.
- هذا المشروع يولّد البرومبتات؛ لا يولّد الصور أو الفيديو مباشرة.

## التحقق

يجب اختبار النشر الفعلي بمفاتيح API صالحة. لم يتم إجراء نشر حي أو اختبار مفاتيح حقيقية أثناء إعداد هذا المشروع.
